# 걸어서 그날까지

목표일까지 하루하루를 지도 위의 한 걸음으로 바꿔 주는 **D-DAY 여정 웹앱(PWA)** 입니다.
서버도 데이터베이스도 없이 정적 파일만으로 동작하고, 여정 데이터는 각자 기기 브라우저에만 저장됩니다.

**바로 열기 → <https://scm21528-eng.github.io/Walk-to-dday/>**

## 무엇을 하나요

- 지도 위에 출발지와 도착지를 찍으면 실제 도보 경로를 따라 여정이 그려집니다.
- 목표일까지 남은 날짜(D-day)와 지금까지 걸어온 거리·진행률을 한눈에 보여 줍니다.
- 여정을 여러 개 만들어 두고, 링크 하나로 가족·친구에게 보낼 수 있습니다.
- 휴대폰 브라우저에서 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열리고, 한 번 열어 두면 오프라인에서도 껍데기가 뜹니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 + 공유 미리보기 메타태그 |
| `styles.css` | 디자인(종이 지도 느낌) |
| `app.js` | 여정 관리·지도·검색·공유·이정표 로직 |
| `routes.js` | 준비된 여정의 실제 도보 경로 데이터 |
| `manifest.json` | PWA 설정(앱 이름·아이콘·시작 주소) |
| `sw.js` | 서비스 워커(오프라인 저장, 버전은 `VERSION`) |
| `icons/` | 앱 아이콘 |
| `og-image.png` | 카카오톡·문자 공유 시 미리보기 이미지 |

## 로컬에서 보기

파일을 직접 열면 지도 타일과 공유가 제한됩니다. 꼭 서버로 열어 주세요.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

## 쓰는 외부 서비스

지도 타일(OpenStreetMap·Esri), 주소 검색(Nominatim), 도보 경로(Valhalla) 세 곳에만 요청이 나갑니다.
모두 OpenStreetMap 기반이며 API 키가 필요 없습니다. 자세한 배포·수정 방법은 `DEPLOY.md`에 정리해 두었습니다.
